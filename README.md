# ElectroVox

Воксельные провода для [Create: Electro Energetics](https://github.com/george8188625/Create-Electro-Energetics).

## Требования
- Minecraft 1.21.1
- NeoForge 21.1.x
- Create 6.0.x
- Create: Electro Energetics 0.5.x+

## Установка
1. Установи NeoForge, Create, CEE.
2. Положи `electrovox-1.0.0.jar` в `mods/`.
3. В `config/electroenergetics-client.toml` установи `disableFlywheelWireRendering = true`.
4. Запусти игру — провода станут воксельными.

## Конфиг
- `voxelWiresEnabled` — вкл/выкл (по умолчанию `true`)
- `wireThickness` — толщина провода в блоках (по умолчанию `0.125` = 2/16)
